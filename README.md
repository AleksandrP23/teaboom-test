# Teaboom — карточка товара

Тестовое задание на позицию HTML-верстальщика

## Запуск

Проект проверен на Node.js 22.23.1. Для запуска нужны Node.js и npm.

В корне проекта выполните:

```bash
npm install
npm run dev
```

Страница откроется по адресу `http://localhost:3000`. Изменения в исходниках автоматически пересобираются и отображаются в браузере.

## Сборка и проверки

```bash
npm run build
```

Команда проверяет стили и форматирование, затем собирает минифицированную версию в папку `app/`. Содержимое этой папки можно разместить на статическом хостинге.

Отдельные проверки:

```bash
npm run stylelint
npm run code
```

При первом запуске `npm run code` проверяющему инструменту EditorConfig может понадобиться доступ к GitHub для загрузки исполняемого файла. Если загрузка недоступна, собрать проект без проверок можно командой:

```bash
npx gulp build --build
```

## Реализовано

- Изображение, название и категория товара, артикул, цены и короткое описание.
- Четыре фасовки: 100, 500, 1000 и 5000 г. При выборе меняются артикул, актуальная и старая цены, сумма выгоды и выбранное состояние.
- Кнопка «В корзину» с состояниями наведения, фокуса и нажатия.
- Адаптивная верстка для desktop, tablet и mobile, включая размеры из задания: 1440, 768 и 375 px. Использованы брейкпоинты сборки: 1024, 768 и 576 px.
- Хлебные крошки, фон в стилистике оригинального сайта и локальные шрифты Open Sans.
- Просмотр фотографии через FsLightbox Basic: открытие по клику, закрытие кнопкой или Escape, возврат фокуса на ссылку.
- Управление фасовками с клавиатуры, заметные состояния фокуса и уведомление скринридера об изменении цены и артикула.

Цены и артикулы взяты из тестового задания и хранятся в JavaScript.

## Технологии и структура

HTML5, SCSS, БЭМ, CSS Grid / Flexbox и JavaScript без frontend-фреймворка. Сборка основана на Gulp-сборке MaxGraph; JavaScript собирается Webpack. Для просмотра фото используется бесплатный FsLightbox Basic.

```text
src/
  index.html                  # Основная страница
  partials/                   # Карточка товара, хлебные крошки и head
  scss/                       # Стили, переменные и адаптивные миксины
  js/components/
    product.js                # Фасовки, артикулы и цены
    product-gallery.js        # Подключение галереи
  img/                        # Фото товара и фон
  resources/                  # Локальные шрифты и favicon
gulp/                         # Задачи и настройки сборки
app/                          # Результат сборки
```

Редактировать нужно файлы в `src/`: папка `app/` пересоздаётся при сборке.
